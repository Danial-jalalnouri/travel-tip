# Project Structure Guidelines

Always use a separated file structure for HTML, CSS, and JavaScript.

## Required Structure

When generating any new feature or page, create the following:

```
project/
├── index.html
├── js/
│   └── script.js
├── css/
│   └── styles.css
└── images/
```

## Rules

- Always separate HTML, CSS, and JavaScript into their own files
- CSS files go in a `css/` folder
- JavaScript files go in a `js/` folder
- If there are any images, they go in an `images/` folder
- Never embed CSS or JavaScript inline in HTML files
- Always maintain an up-to-date `README.md` file in the project root
- The README should contain a clear explanation of the codebase and its features
- Whenever the code is updated, the README must also be updated to reflect the changes

## MUST DO — Before Completing Any Task

1. Verify all files follow the structure above.
2. **Always create or update `README.md`** with an explanation of what was built and how it works.
3. If you modified existing code, update the README to reflect the changes.
